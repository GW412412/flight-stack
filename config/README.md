# Example configs

All files here are **examples** derived from public ArduPilot documentation concepts.

- They are **not** vendor-certified parameter sets.
- Channel numbers (`SERVO9`, `SERIAL2`, `RC7`) vary by flight controller — always verify.
- Calibrate `SPRAY_PUMP_RATE` for your nozzles and target L/ha before chemical use.

Primary references:

- https://ardupilot.org/copter/docs/common-sprayer.html
- https://ardupilot.org/dev/docs/raspberry-pi-via-mavlink.html
