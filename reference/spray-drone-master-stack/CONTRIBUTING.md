# Contributing

## Before changing code
1. Read README.md and AGENTS.md.
2. Read the relevant master-plan, architecture, requirements and safety documents.
3. Keep changes small and state which requirements they address.

## Validation
- Run the tests and checks relevant to your change.
- Record exact commands and outcomes.
- Do not describe unrun checks as passing.

## Safety boundary
This repository is not flight-ready. Work in simulation or read-only mode by default. Do not enable real vehicle or spray actuation without the documented reviews and acceptance evidence.

## Changes
Use a focused branch and reviewable commits. Do not commit credentials, private configuration, raw sensitive telemetry or generated datasets without review.
