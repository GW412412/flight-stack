Where to look things up. All links checked 23 Oct 2026.

## ArduPilot source code (GitHub)
- [ArduPilot firmware](https://github.com/ArduPilot/ardupilot): the Copter code, parameters in the source, Lua scripting
- [AP_Scripting (Lua) folder](https://github.com/ArduPilot/ardupilot/tree/master/libraries/AP_Scripting): bindings, examples, applets
- [ArduPilot wiki source](https://github.com/ArduPilot/ardupilot_wiki): the docs in Markdown/RST, searchable on GitHub
- [pymavlink](https://github.com/ArduPilot/pymavlink): Python MAVLink library
- [MAVProxy](https://github.com/ArduPilot/MAVProxy): command-line ground station and router
